# Yayın sayfaları

`index.html` projenin tanıtım sitesidir (Metro dilinde, tek dosya, `img/` içindeki görselleri
kullanır). `gizlilik.html` ve `privacy.html` ise `PRIVACY.md` ve `PRIVACY.en.md` dosyalarından
üretildi. **Gizlilik metnini bunlarda değil, o iki markdown dosyasında düzenle**; HTML'i
yeniden üretmek yerine elle değiştirirsen ikisi birbirinden ayrılır.

GitHub Pages'i açmak için: repo → Settings → Pages → Source: `main`, klasör: `/docs`.
Adres şu olur:

- Tanıtım sitesi: `https://serkantkn.github.io/Z-Launcher/`
- Gizlilik, Türkçe: `https://serkantkn.github.io/Z-Launcher/gizlilik.html`
- Privacy, English: `https://serkantkn.github.io/Z-Launcher/privacy.html`

Play Console'da "Gizlilik Politikası" alanına gizlilik sayfasının adresini yaz. Yayımlamadan önce her iki
dosyadaki **iletişim e-posta adresi** yer tutucusunu doldurmayı unutma.

`img/` klasöründeki ekran görüntüleri ve GIF'ler kökteki `README.md` içindir; emülatörde,
örnek içerikle alındı. Yenilemek gerekirse aynı adlarla üzerine yazmak yeter.
