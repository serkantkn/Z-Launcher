# Yayın sayfaları

Buradaki iki HTML, `PRIVACY.md` ve `PRIVACY.en.md` dosyalarından üretildi. **Metni bunlarda
değil, o iki markdown dosyasında düzenle**; HTML'i yeniden üretmek yerine elle değiştirirsen
ikisi birbirinden ayrılır.

GitHub Pages'i açmak için: repo → Settings → Pages → Source: `main`, klasör: `/docs`.
Adres şu olur:

- Türkçe: `https://serkantkn.github.io/Z-Launcher/`
- English: `https://serkantkn.github.io/Z-Launcher/en.html`

Play Console'da "Gizlilik Politikası" alanına bu adresi yaz. Yayımlamadan önce her iki
dosyadaki **iletişim e-posta adresi** yer tutucusunu doldurmayı unutma.

`img/` klasöründeki ekran görüntüleri ve GIF'ler kökteki `README.md` içindir; emülatörde,
örnek içerikle alındı. Yenilemek gerekirse aynı adlarla üzerine yazmak yeter.
